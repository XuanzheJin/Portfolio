Use case narrative: Upload Image
ActorStaff
PreconditionThe staff member is logged in through the staff login.
Main flow1. The staff member selects Upload Image.
2. The system displays the Upload Image page.
3. The staff member chooses an image file, adds a description and selects Upload.
4. The system checks the file.
5. The system saves the image and shows a confirmation message.
Alternative flowIf the file is not valid, the system shows an error message and the staff member can choose another file.
PostconditionThe image is saved and available in the system.
